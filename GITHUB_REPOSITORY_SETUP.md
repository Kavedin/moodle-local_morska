# GitHub repository setup for Morska

Repository: https://github.com/Kavedin/moodle-local_morska

## Recommended repository settings

1. Keep the repository public so Moodle Marketplace reviewers and users can access the source and issue tracker.
2. Enable GitHub Issues.
3. Add repository topics such as `moodle`, `moodle-plugin`, `accessibility`, `h5p`, `scorm`, `text-to-speech`, and `elearning`.
4. Set the website field to `https://ktc.co.ug/downloads/morska/`.
5. Use Releases for official Marketplace candidate and stable packages.
6. Do not publish private signing keys, licence-server credentials, customer licence keys, or production secrets.
