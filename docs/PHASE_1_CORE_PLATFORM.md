# Morska Accessibility Platform - Phase 1 Core Platform

This release begins the transition from a feature-based local plugin to a modular accessibility platform.

## Added scaffolding

- Context Engine
- Module Manager
- Preference Manager
- Reading Queue helper
- Event Manager
- Accessibility Manager
- Logger
- Generic Moodle Connector
- H5P Connector scaffold
- SCORM Connector scaffold
- Administrator module settings

## Purpose

The goal of Phase 1 is to create the platform backbone that future modules will plug into, including Reader, Vision, Language, Navigation, Speech, AI, Analytics, H5P, SCORM, and Authoring tools.


## v3.3.3 alpha - Interaction Engine

Added an early Interaction Engine for H5P and SCORM. It can prepare interactive screens by expanding accordions/details, activating visible tabs, revealing hotspots, and flipping accessible flashcards where same-origin browser access permits. Assisted mode avoids automatic Next/Continue navigation; automatic mode is experimental.
